## Notes / Issues

1. **LLM stub mode confirmed.** With no API keys, `POST /api/heal` returns a deterministic stub (`hasLLM:false`). An `OPENAI_API_KEY` present in the shell environment (not from repo files) caused `hasLLM:true` and a 500 on auth failure — correct documented behavior with an invalid key. The repo ships with empty keys.
2. **`@langchain/core` version bump** (0.3.37 → 0.3.80) was required to satisfy `langchain`'s transitive peer range and resolve `@langchain/core/messages`.
3. **`expo-image-picker` was missing** and added via `npx expo install` (SDK-matched).
4. **Tailwind config** was required by NativeWind 4 to run Metro/export; created with the app's design tokens.
5. French asset names present in `assets/` were referenced correctly in `app.json` (icon, favicon, splash-icon, android-icon-*).
